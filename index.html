使い方と準備

このアプリは このHTMLファイル1つ で動きます。Chrome・Edge でファイルを開くだけで使えます（インストール不要）。作った楽譜や設定はこのブラウザの中に保存されます。

作った楽譜や設定はこのPCの中（このアプリ専用の保存場所）に保存されます。

① 楽譜を読み取る方法を1つ用意する

🎯 楽譜の読み取り精度は homr が断然おすすめです。テストでは、スマホで撮った楽譜写真でも104音すべてを正しく読み取りました（AIは調号や音の高さを読み違えやすい）。無料・APIキー不要です。

A. 楽譜読み取り専用ソフト homr（いちばんおすすめ・無料・高精度）
PCで小さな補助プログラムを動かしておくと、自動でそちらを使って読み取ります。 補助プログラムはこのアプリが自動で起動します（Python などのインストールは不要）。homr 本体は、初回だけ「homr の準備画面」の 「homr をインストールする」ボタンでインストールします（約750MB・数分〜十数分）。

補助プログラム：確認中…

        
        
      

      
    
        
  1. Python を入れる（初回のみ）。python.org から Python 3.13 をインストール。Windowsは最初の画面で 「Add python.exe to PATH」にチェック。Macはインストール後「アプリケーション → Python 3.13 → Install Certificates.command」をダブルクリック。
    2. 
        
  2. 下のボタンで補助プログラムを同じフォルダに保存（どちらも必要です）
    
          
          
    3. 
        
  3. Windows：保存した start_helper_windows.bat をダブルクリック（青い警告は「詳細情報」→「実行」）。
    
          Mac：ターミナルを開き cd ~/Downloads → python3 pkm_omr_helper.py
    4. 
        
  4. 初回は部品と homr の準備（約900MBのダウンロード）があります。「補助プログラムを起動しました」と出たら準備完了。そのウィンドウは開いたままにします。
    5. 
      

      
補助プログラムはこのPCの中からの接続だけを受け付け、画像を外部に送りません。Audiveris（スキャン楽譜向け）は GitHub の公式配布 から入れると自動で使えます（audiveris.com / .net は無関係の危険なサイトです）。

      
B. AI（homr を使わない場合・精度は homr より下がります）
「⚙ 設定」で Claude・ChatGPT・Gemini・Grok のどれかの APIキーを入力します（利用料はAI各社に直接かかります）。

      
「⚙ 設定 → 使い方」が「自動」なら、補助プログラムが動いていれば homr、なければAIで読み取ります。

  • 画像をドロップ／「＋ 画像」／Ctrl+V で貼り付け（複数ページ可・iPhoneのHEICも可）。Webページの画像はこの画面へドラッグ。
    • 
        
  • 「全ページを解析して1曲に」。黄色の ⚠ は要確認の小節です。音のチップをクリックして直せます。

保存について

      
    
        
  • 「保存」でこのブラウザ内のライブラリに入ります。ブラウザの閲覧データを消すと消えるので、大事な楽譜は「書き出し」でファイルにも残してください。
    • 
        
  • 保存先はブラウザと開いた場所ごとに別です（PC上のファイルとWeb公開版は別のライブラリになります）。
